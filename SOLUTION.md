## Решения

- **Статусы.** В «Предстоящие» отнёс `scheduled`, `live` и `postponed` — всё, что ещё не доиграно: идущий матч пока не завершён, перенесённый ещё будет сыгран. В «Завершённые» — только `finished`. Незнакомый статус (например, если сервер пришлёт `cancelled`) не отношу ни туда, ни туда: такой матч виден во вкладке «Все» с исходным статусом, а не пропадает.
- **Неочевидные случаи в данных:**
  - `startsAt: null` у перенесённого матча — показываю «Дата уточняется» и ставлю такие матчи в конец списка (сортировка по времени начала). Невалидная дата обрабатывается так же;
  - `score: null` у несыгранных матчей — вместо счёта «– : –»;
  - у идущего матча есть поле `minute`, которого нет у остальных, — показываю «Идёт · 67′»;
  - время в данных в UTC (`...Z`) — `Date` переводит его в часовой пояс устройства, форматирую через `toLocaleString('ru-RU')`.
- **Загрузка.** Проверяю `response.ok` и формат ответа (`matches` — массив), иначе это ошибка, а не падение экрана. Предыдущий запрос отменяю через `AbortController`, чтобы поздний ответ не перезаписал свежие данные.
- **`MATCHES_URL`.** В шаблоне был плейсхолдер `OWNER/REPO` — по нему GitHub отвечает 404. Подставил адрес своей копии репозитория: файл `data/matches.json` тот же, источник данных не менял.

## Баги из части 2

1. **Звёздочки.** `isFavorite` возвращал `Boolean(favorites.indexOf(id))`: для отсутствующего id `indexOf` даёт `-1`, а `Boolean(-1) === true`, поэтому все звёзды горели, а «не избранным» считался только матч на позиции 0. Вдобавок `toggle` мутировал массив из state (`push`/`splice`) и передавал в `setFavorites` ту же ссылку — React сравнивает по ссылке, не видит изменений и не перерисовывает, поэтому нажатие то «не срабатывало», то проявлялось при случайном следующем рендере. Исправил: `includes` и новый массив через функциональный `setFavorites(prev => ...)`.
2. **«Обновлено N сек назад».** Эффект с пустыми зависимостями запускался один раз, и колбэк `setInterval` навсегда замкнул `seconds = 0` — каждую секунду выполнялось `setSeconds(0 + 1)`, так что число застывало на 1. Проп `since` не использовался вовсе, поэтому после обновления подпись не сбрасывалась; интервал ещё и не очищался при размонтировании. Исправил: таймер только обновляет «текущее время», а секунды считаются как `now − since` при каждом рендере — новый `since` сразу даёт 0; интервал очищается в cleanup.

## Как я использовал ИИ

Claude Code: разбор проекта, план коммитов, код, проверки (`tsc`, `expo lint`, сборка под web и скриншот в headless Chrome, прогон логики фильтра на `matches.json`).

- Первая версия `UpdatedAgo` и `useMatches` вызывала `setState` прямо в теле `useEffect` — typecheck это пропустил, поймал `expo lint` (`react-hooks/set-state-in-effect`). Переписал: в `UpdatedAgo` таймер двигает только «сейчас», в `useMatches` состояние меняется в колбэках запроса.
- Агент переписал уже запушенные коммиты (влил туда фиксы после lint), посчитав, что они ещё локальные, — `git pull` упал с divergent branches. Проверил разницу (отличались только эти два файла) и перезаписал ветку через `push --force-with-lease`.
- Насчёт `MATCHES_URL` агент сразу подставил адрес своего репозитория, хотя в комментарии «адрес менять не нужно». Проверил `curl`: плейсхолдер отдаёт 404 — без замены экран не работает.
